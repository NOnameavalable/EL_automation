# Project Memory Index

This folder stores durable project context for future coding work.

Always read this file first before changing code. Then read the files below in
order.

## Required Read Order

1. `memory/PROJECT_CONTEXT.md`
2. `memory/PROJECT_RULES.md`
3. `memory/DECISIONS.md`
4. `memory/NEXT_STEPS.md`

## Maintenance Rules

- Keep each memory file under 200 lines.
- Store stable project facts, not temporary debugging notes.
- Update memory after meaningful architecture, workflow, or behavior changes.
- Remove or revise stale entries when implementation changes.
- Do not store secrets, credentials, private keys, tokens, or sensitive values.
- Prefer paths, setup notes, and design reasoning over chat-history summaries.
